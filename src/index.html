What's different

HD, any window

Any window size or full screen, sharp at today's resolutions. A lit HD terrain and a 3D world map that zooms.

Modern UI

A second interface at the window's real size, panels over the live map. Every control of the original, under its own name.

Android

Played by touch on a tablet. Tried on the emulator so far.

Multiplayer that works

Network play over TCP/IP: Windows and Mac players in one game. Join by a code or from the public list, no port to open.

Hotseat

Several players at one computer, taking turns. A screen hides each player's empire from the next.

Getting started

  1. Get Deadlock 2. Installed from the CD, Steam or GOG, or just GOG's installer: OpenDeadlock reads the game's files from either.
  2. Download OpenDeadlock for your system from the latest release and unpack it anywhere.
  3. Start OpenDeadlock and select your Deadlock 2 folder or GOG's installer. On macOS, run xattr -dr com.apple.quarantine . in OpenDeadlock's folder once first. Linux has no folder dialog: put OpenDeadlock's files in the Deadlock 2 folder itself, put GOG's installer in OpenDeadlock's folder, or name either as gamedir= in opendeadlock.ini.
