Changelog

What each release changed against the original Deadlock 2, one line a change. Each line links to its details in the full changelog: why, how it was checked, before/after screenshots and the port's own fixes. What's new has every change by where in the game.

v0.3.1 2026-11-25

5 changes · 5 port fixes

  • The modern UI draws the toasts and the Shift hint itself (Interface)
  • Battle replays: the battle log names what destroyed each unit, and shows five lines (Battle)
  • The network lobby's chat scrolls back (Multiplayer)
  • The rules set before a network game is hosted, again (Multiplayer)
  • macOS: one "Apple could not verify" question, not three (System)

v0.2.0 2026-11-22

  • The modern building panel's tasks have - and + beside them: workers moved without a drag (Colony, Interface)
  • The modern UI shows costs with the resources' pictures (Interface)
  • Computer players' attackers withdraw when badly damaged, as in Deadlock 1 (AI)
  • The campaign's briefing is read on Campaign Selection, with its voice on request, and Next Scenario comes back there (Scenarios)
  • The campaign keeps which missions were won, and the modern Campaign screen starts any of them (Scenarios)
